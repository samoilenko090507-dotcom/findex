## Зведені результати вимірювань (Лабораторні роботи 1–8)

### 1. Порівняння затримки BM25 (Лабораторна 3 vs Векторизація NumPy)

| Запит | Тип запиту | Чистий Python (Лаба 3) | NumPy векторизація (Лаба 8) | Прискорення |
|---|---|---|---|---|
| новини | Частий термін | 14.82 ms | 1.15 ms | **~12.8x** |
| диверсифікація | Рідкісний термін | 1.24 ms | 0.82 ms | **~1.5x** |
| швидкий пошук векторів | Запит із 3 слів | 21.40 ms | 2.10 ms | **~10.2x** |

### 2. Оцінка якості семантичного та гібридного пошуку (Precision@5)

| Набір запитів | Кількість | BM25 P@5 | Semantic P@5 | Hybrid (RRF) P@5 |
|---|---|---|---|---|
| Точні терміни (Лабораторна 3) | 10 | 0.88 | 0.78 | **0.94** |
| Перефразовані без ключових слів | 5 | 0.16 | 0.84 | **0.88** |
| **Середня точність** | **15** | **0.65** | **0.80** | **0.92** |

## Технічні обмеження рушія

- **Використання оперативної пам\'яті:** Матриця семантичних ембедингів завантажується безпосередньо в RAM. Для корпусів обсягом понад 500,000 документів необхідно переходити на шардинг або memory-mapped векторні сховища (наприклад, HNSWlib / FAISS).
- **Холодний старт моделі:** Перший запит у режимах semantic та hybrid ініціалізує ваги нейромережі трансформера MiniLM, що призводить до одноразової затримки запуску близько 1.5–2.0 секунд.
- **Морфологічна нормалізація:** Базовий лексичний токенізатор орієнтований на регулярні вирази, тому складні морфологічні форми без стемінгу можуть мати дещо нижчий показник повноти (recall) у чистому BM25.
